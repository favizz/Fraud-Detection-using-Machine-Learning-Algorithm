Fraud Detection — Live Demo

Decision Tree (C4.5) and Logistic Regression models, implemented from scratch in numpy and trained on the transaction dataset, running as plain JavaScript in this page. Nothing you enter here is sent anywhere.

Tip: leave "Transaction amount", "Avg. transaction amount" or "Device trust score" blank to see how the pipeline imputes missing values, just like in the real dataset.

Preprocessing (imputation, feature engineering, outlier clipping, encoding, scaling) and model weights were exported from the training notebook via scripts/export_model.py into web/data/*.json and re-implemented here in preprocess.js — no server, no API calls, static hosting only.
